# Sharqey CLI

Command-line client for [Sharqey](https://sharqey.com), the end-to-end
encrypted password manager for teams: read secrets in scripts and CI, inject
them as environment variables, work with local `.sharqey` databases.

## Install

```sh
brew install sharqey/tap/sharqey
```

or download a binary from [Releases](https://github.com/sharqey/cli/releases/latest)
(macOS and Linux, amd64 and arm64; checksums in `checksums.txt`).

This repository currently hosts releases only; the source code is not public yet.
Questions and bug reports: [sharqey.com/support](https://sharqey.com/support).
